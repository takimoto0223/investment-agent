# アクティビスト大量保有ウォッチ（2026-08-12 時点）

対象期間: 2025-07-27〜2026-08-12 の大量保有報告書・変更報告書（新規保有・買い増し中心）。

## データの素性（重要）
- 本レポートは **WebSearch による報道ベースの調査**。実行環境のネットワークポリシーで
  buffett-code / irbank / maonline / EDINET / yfinance への直接アクセスが遮断されていたため、
  一次ソース（EDINET原本）・リアルタイム株価は未参照。
- 株価はすべて **⚠暫定値**（報道・市況記事からの採取。時点を併記）。
- エントリー水準との厳密な比較は `scripts/activist_entry_screen.py` を
  ネットワーク制限のないローカル環境で実行して行うこと:
  ```
  pip install yfinance
  python scripts/activist_entry_screen.py --out report/activist_screen.md
  ```
